# Install with:
#     pip install -r requirements.txt
#
# Sections in this file, in order:
#
#   0. System packages (not pip-installable — documented as comments
#      so the file is a complete deployment reference).
#   1. Direct runtime dependencies — the packages the application
#      imports or loads by name.
#   2. Transitive runtime dependencies — pulled in by the direct set
#      above. Pinned for reproducible builds. Do not hand-edit these

# ═════════════════════════════════════════════════════════════════════
# 0. SYSTEM PACKAGES
# ═════════════════════════════════════════════════════════════════════
#
# Install on the host before the Python environment. Required for the
# reverse-proxy / TLS / smoke-test stack documented in the deployment
# notes.
#
#     sudo apt install nginx openssl curl
#
# `nginx`    — reverse proxy terminating TLS on port 5443.
# `openssl`  — generates the self-signed certificate for the `5443`
#              listener.
# `curl`     — smoke-tests endpoints during setup and after deploy.
#
# ── mysqlclient compile-time headers ──────────────────────────────
#
# `mysqlclient` (section 1) requires the MariaDB / MySQL client
# headers at compile time. On Debian / Ubuntu:
#
#     sudo apt install default-libmysqlclient-dev build-essential pkg-config
#
# If you cannot install build tools on the target host, replace
# `mysqlclient` in section 1 with `PyMySQL` and add
#
#     import pymysql
#     pymysql.install_as_MySQLdb()
#
# to config/__init__.py. PyMySQL is pure Python and installs without
# a compiler, at the cost of some per-query overhead.
#
# ── WeasyPrint runtime libraries ──────────────────────────────────
#
# `weasyprint` (section 1) is a Python wheel that dlopens several C
# libraries at import time. Without them, `import weasyprint` raises
# an OSError naming the missing .so file, and PDF export returns a
# 500. On Debian / Ubuntu (Bookworm and newer):
#
#     sudo apt install libpango-1.0-0 libpangoft2-1.0-0 \
#                      libharfbuzz0b libcairo2 \
#                      libgdk-pixbuf-2.0-0 libffi8
#
# On Fedora / RHEL:
#
#     sudo dnf install pango pangoft2 harfbuzz cairo gdk-pixbuf2 libffi
#
# On Alpine (commonly used in slim container images):
#
#     apk add pango pango-dev harfbuzz cairo gdk-pixbuf libffi
#
# Installing WeasyPrint WITHOUT these libraries is a supported state:
# the app starts, every other export format works, and the PDF branch
# returns a 500 with a clear message. The docker / apt lines above
# only need to be run on hosts where PDF export is actually wanted.
#
# ── Arabic font for PDF export ────────────────────────────────────
#
# PDF export embeds a Noto Sans Arabic TTF so the generated file
# carries its own glyphs. The file is already shipped inside the repo
# at:
#
#     frontend/public/fonts/NotoSansArabic-VariableFont_wdth,wght.ttf
#
# pdf_export.py looks for it at (in order):
#
#     1. settings.FRONTEND_DIR / 'public' / 'fonts'
#     2. settings.BASE_DIR / 'static' / 'fonts'
#
# Development runs satisfy (1) automatically. A production host that
# ships only the built `frontend/dist/` tree should copy the TTF to
# `backend/static/fonts/` during the build:
#
#     mkdir -p backend/static/fonts
#     cp frontend/public/fonts/NotoSansArabic-VariableFont_wdth,wght.ttf \
#        backend/static/fonts/
#
# A missing font is not fatal — the PDF is still generated, using
# whatever system font Pango falls back to, and a warning is logged
# naming the two paths that were checked.
# ── MariaDB timezone tables ──────────────────────────────────────
#
# Django's TruncMonth / TruncWeek / TruncDate on a tz-aware
# DateTimeField compile to CONVERT_TZ(..., 'UTC', <TIME_ZONE>).
# On a stock Debian/Ubuntu install the mysql.time_zone* tables
# are empty, so CONVERT_TZ returns NULL and Django raises:
#
#   ValueError: Database returned an invalid datetime value.
#   Are time zone definitions for your database installed?
#
# Load them once per server (idempotent — safe to re-run):
#
#     sudo mysql_tzinfo_to_sql /usr/share/zoneinfo | sudo mysql mysql
#
# MariaDB also wants the tz tables populated for TIMESTAMP column
# arithmetic, so this is worth doing regardless of the app.

# 4. BOOTSTRAP SEQUENCE (documentation only — do not uncomment)
# ═════════════════════════════════════════════════════════════════════
#
# Run from `backend/` with the virtualenv activated and `backend/.env`
# populated. See backend/.env and backend/config/settings.py for the
# required keys.
#
# ── First-time setup ─────────────────────────────────────────────────
#
#   python -m venv .venv
#   source .venv/bin/activate
#   pip install -r requirements.txt
#
#   # Schema + seed data — pick ONE path:
#
#   # Path A — incremental (existing database, or first schema already
#   # applied). Runs each seeder individually so failures are easy to
#   # localise:
#   python manage.py makemigrations
#   python manage.py migrate
#   python manage.py seed_data
#   python manage.py seed_sample_questions
#
#   # Path B — clean rebuild (development only; DESTROYS the database).
#   # Drops every table, deletes every migration file for the custom
#   # apps, regenerates 0001_initial.py, migrates, and runs the `seed`
#   # wrapper. The wrapper's default set is seed_data, seed_tips, and
#   # seed_capabilities. Pass --with-sample-questions to include
#   # seed_sample_questions:
#   python manage.py bootstrap --clean --with-sample-questions
#
#   # Capabilities — skipped when `bootstrap` was used (the seed
#   # wrapper already ran it). Run explicitly otherwise, or to reset
#   # panel edits back to code defaults:
#   python manage.py seed_capabilities
#   # python manage.py seed_capabilities --reset
#
#   python manage.py collectstatic --noinput
#   sudo ufw allow 5443/tcp
#   python manage.py runserver 0.0.0.0:5004
#
# ── Initial admin credentials ────────────────────────────────────────
#
# `seed_data` creates a single `admin` account and prints the initial
# password to stderr once. The account is created with
# `must_change_password=True`; MustChangePasswordMiddleware will
# refuse every API and /admin/ request except the change-password
# flow until the password is changed on first login.
#
# To reset the admin password at any time:
#
#   python manage.py reset_admin_password
#   python manage.py reset_admin_password --qr
#
# The command prints the new password to stderr, sets
# `must_change_password=True`, and (with --qr) renders an ASCII QR
# code for the credential.
#
# ── Static files ─────────────────────────────────────────────────────
#
# `collectstatic` copies Django admin's CSS/JS from site-packages into
# backend/staticfiles/. Without it, /admin/ loads unstyled. Re-run
# after every Django or third-party-app upgrade.
#
# ── PDF export smoke test ────────────────────────────────────────────
#
# After `pip install -r requirements.txt`, confirm WeasyPrint's system
# libraries are present before deploying:
#
#   python -c "import weasyprint; print(weasyprint.__version__)"
#
# A shared-library error here means section 0's apt/dnf/apk line for
# this host has not been run. The app will still start without it;
# only the `fmt=pdf` export will return a 500.
